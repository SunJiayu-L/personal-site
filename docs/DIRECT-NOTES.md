# 在原笔记中控制发布

CS285N 读取私人 Computer / RL 目录下的原笔记，不再读取 Notes 中的旧副本。

1. 在 RL 页面下新建普通子页面，正常写笔记。
2. 使用 `/todo` 在正文最顶部创建待办框，文字准确填写「发布到网站」。
3. 不勾选或不添加开关：不发布。勾选：下一次成功同步后发布。取消勾选或删除开关：下一次成功同步后撤下。
4. 已勾选时，原笔记的后续修改也会自动发布。网站每小时同步；也可手动运行 Pages 工作流。

开关必须是正文第一块，不能放在标题下方的其他文字后面、折叠块中或列表内部。开关本身不会显示在网站正文中。已发布内容包含笔记正文、图片和折叠内容；需要保密的文字请放在另一篇未发布笔记中。子页面不会自动递归公开，数据库和深层页面不在本模式的扫描范围内。

课程元信息只需配置一次：在 Courses 的 Notebook 中填私人课程目录的 Notion 链接，勾选课程 Published，并向网站集成授权该目录及其子页面。未登记的目录不扫描。新课程可以沿用此模式。移除 Notebook 前请确认 Notes 中没有需要保持隐藏的旧副本。

新笔记自动使用标题、创建日期及在目录中的顺序；网址由原页面 ID 生成，改标题不会改变网址。现有 CS285N 文章通过 config/notebook-routes.json 保留原网址。原始 Notion 页面无需开启互联网公开分享。

Blog 当前仍使用后台 Blog 数据库的 Published 属性；若要从私人博客目录发布，需要另行登记该目录及分类，不能仅在任意私人页面加勾选框就发布。

读取失败时构建停止，保留上一次成功的网站；因此网络或权限故障期间，取消勾选不会即时撤回。需要确认 GitHub Actions 成功完成。
